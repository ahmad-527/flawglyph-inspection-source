development project. The browser title, visible header, API title and package
description use FlawGlyph. Historical modules, commands, API identities and
distribution names remain compatible.

Install the matching reviewed visionguard-ai core distribution before the
separate visionguard-inspection package. Matching version strings alone do not
establish matching source. Package-index publication is a separate action.

fixture on loopback. It demonstrates the interface and provides no learned-model
or accuracy claim. Without an explicitly authorised registry or the demo flag,
the application remains not ready. Trained loading or inference requires
separate exact-artifact authority and a separately reviewed runtime; this source
snapshot creates no authority. Previously consumed authorisations remain spent.
