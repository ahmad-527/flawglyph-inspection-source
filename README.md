# FlawGlyph — source-only research snapshot

Visual anomaly inspection and defect-localization research. The name suggests
visible marks for locating potential visual defects; it is not an accuracy
claim. FlawGlyph is a provisional presentation name for the historical
VisionGuard development project. This snapshot preserves its Python modules,
distribution names, commands, model identifiers and API compatibility.

See [the inspection application](apps/inspection/README.md). Manufactured checks
exercise installation, image dimensions, finite outputs, immutable identities,
guarded native restoration and API/browser lifecycle. They establish no accuracy
or historical prediction-equivalence claim.
